# Renan Alves de Oliveira - Portfolio

Modern portfolio website showcasing my work as an AI Specialist, Data Scientist, and Astrophysicist.

## 🌟 Features

- **Modern Dark Theme**: Sophisticated dark color scheme with liquid glass (glassmorphism) effects
- **Fully Responsive**: Optimized for all devices from mobile to desktop
- **Smooth Animations**: Engaging scroll-based animations and interactive elements
- **Performance Optimized**: Fast loading times with optimized assets and code via Vite
- **SEO Friendly**: Proper meta tags and semantic HTML structure

## 🚀 Live Demo

Visit the live portfolio at: [https://oliveirara.github.io/cv](https://oliveirara.github.io/cv)

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for better accessibility
- **CSS3**: Modern CSS with custom properties, glassmorphism, and animations
- **Vanilla JavaScript**: No frameworks, pure JS for optimal performance
- **Vite**: Modern frontend build tool for fast development and optimized builds
- **GitHub Actions**: Automated deployment to GitHub Pages

## 💻 Desenvolvimento Local

### Pré-requisitos

- Node.js (v16 ou superior)
- npm (incluído com Node.js)

### Instalação e Execução

1. Clone ou navegue para o repositório:
```bash
cd /home/renan/cv
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

O servidor será iniciado em **http://localhost:3000** e abrirá automaticamente no navegador.

### Comandos Disponíveis

```bash
# Desenvolvimento (com hot reload)
npm run dev

# Build para produção
npm run build

# Preview da versão buildada
npm run preview
```

## 🚀 Deployment

This portfolio is automatically deployed to GitHub Pages using GitHub Actions. Every push to the `main` or `master` branch triggers a new deployment.

### Manual Deployment

If you need to deploy manually:

1. Go to your repository settings
2. Navigate to "Pages" section
3. Select "GitHub Actions" as the source
4. The workflow will run on the next push

## 📝 Customização

To customize this portfolio for your own use:

1. Update `src/index.html` with your personal information
2. Modify the color scheme in `src/styles.css` (CSS variables at the top)
3. Replace the CV PDF file in `public/` with your own
4. Update social media links and contact information
5. Organize your images in `src/assets/images/`
